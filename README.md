## ESP32 projects
This repository includes many projects using the ESP32 S3 DEV kit.

## Project list
1. Environmental sensor - This project is the first practice using and displaying the temp, humidity and pressure on the oled Display.
2. Environmental sensor web - This project is a extension of the Environmental sensor project where it creates a website to display the data.


## Hardware
ESP32 S3 DEV kit
BME280 Environmental sensors
1.54 Inch OLED Module waveshare
VL53L1x TOF sensor
